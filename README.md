# nyuk.pe

Una boutique de flores premium con experiencia editorial inspirada.

## Características

- 🌸 Catálogo de productos premium
- 🛒 Carrito de compras funcional
- ❤️ Lista de deseos
- 📱 Diseño responsive
- 🎨 Animaciones elegantes
- 📊 Integración con Google Sheets

## Tecnologías

- React 19 con TypeScript
- Vite
- TailwindCSS
- Lucide React Icons

## Ejecutar Localmente

**Prerrequisitos:** Node.js

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Ejecutar la aplicación:
   ```bash
   npm run dev
   ```

3. Abrir http://localhost:3000 en tu navegador

## Build de Producción

```bash
npm run build
```

## Estructura del Proyecto

```
src/
├── components/     # Componentes React
├── services/       # Servicios de API
├── types.ts        # Definiciones TypeScript
├── constants.tsx   # Datos estáticos
└── App.tsx         # Componente principal
```
